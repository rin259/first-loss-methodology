## arXiv

An arXiv preprint under `cs.SE` is planned. Once assigned, add the arXiv ID here and update `CITATION.cff` with:

```yaml
identifiers:
  - identifier: "arXiv:XXXX.XXXXX"
    type: arxiv
    description: "arXiv preprint"
```

And update `citation.bib` with:

```bibtex
eprint = {XXXX.XXXXX},
archivePrefix = {arXiv},
primaryClass = {cs.SE},
```
